# Awesome DESIGN.md

A comprehensive library of 84 verified `DESIGN.md` design system specifications extracted directly from developer-focused platforms, design powerhouses, and global brands.

Each `DESIGN.md` contains:
- **Visual Theme & Atmosphere**: Density, lighting, surface philosophy, and brand personality.
- **Color Palette & Roles**: Exact hex codes, semantic tokens (background, surface, border, primary, muted, destructive), and contrast rules.
- **Typography Rules**: Primary and monospace typefaces, weights, line-heights, tracking, and full typographic hierarchy.
- **Component Styling**: Buttons, input fields, cards, badges, dropdowns, navigation, and modal dialogues.
- **Layout & Spacing**: Grid systems, containers, padding scales, gap hierarchies.
- **Depth & Elevation**: Border radii, border styles, shadows, and z-index layers.
- **Do's and Don'ts**: Concrete guardrails and anti-patterns.
- **Ready-to-Use Agent Prompts**: Targeted instructions for generating matching code.

## How to Use This Skill

When a user asks to style a project, component, or website after a specific brand:

1. **Locate the specification**:
   Look inside `design-md/<brand>/DESIGN.md` in this skill directory.
   Example: To style like Stripe, read `.agents/skills/awesome-design-md/design-md/stripe/DESIGN.md`.

2. **Inspect the DESIGN.md**:
   Extract:
   - Primary & background colors (`--color-primary`, `--color-bg`, etc.)
   - Font family and typography scale
   - Border radius and shadow variables
   - Button, card, and navigation patterns

3. **Apply the tokens**:
   Implement the exact CSS variables, Tailwind configuration, or component markup specified in the document.

4. **Optional - Copy to project root**:
   If requested, copy `design-md/<brand>/DESIGN.md` directly into the project root as `DESIGN.md`.
